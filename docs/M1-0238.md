# M1 — proof-state set ranker

Worktree: `/research/dlm_v0.0238/experiments/m1_proof_state`

## What changed

- Input: proof state + candidate-action features (not MNIST image bits).
- Label: kernel-oracle utility (Δclosure goal gain minus rule cost).
- Split: disjoint entity ranges, not random rows.
- Model: 2-layer set transformer, no positional encoding, scalar per-candidate
  score.
