# 설계 — 연역학습용 transformer 구조 탐색 (0.0247)

목표: 손으로 고른 변형 몇 개를 비교하는 단계에서, **연역에 맞는 구조를 탐색하고
발견하는 절차**로 넘어간다. 0.0246에서 데이터(교사 상태)와 표현(goal binding)을
고정해 두 축의 효과를 분리했으므로, 이제 남은 변수는 **셀 구조**다.

## 1. 발견 신호: 분포 내 성능이 아닌 구조 이동 일반화

분포 내(같은 깊이) 비교는 데이터·표현 효과에 압도된다(0.0246: +45pp). 구조의
효과는 **학습 분포를 벗어난 구조 이동**에서 드러난다. 측정 사다리(ladder):

```text
ID        d=2, b=4     학습과 동일
depth     d=3, b=4     목표가 3개 규칙 조합을 요구
          d=4, b=4     목표가 4개 규칙 조합을 요구
budget    d=2, b=6     탐색 예산만 확대
          d=4, b=6     깊이·예산 동시 확대
```

세계(facts·seed 규칙·후보)는 깊이와 무관하게 동일하고 목표 풀만 달라진다
(`make_world`의 goal shuffle을 로컬 RNG로 분리). 그래서 같은 가중치를 서로 다른
목표 난이도에 그대로 평가할 수 있다.

## 2. 기준선 측정 (0.0247, d=2/b=4 학습, 3 시드, RELOB+full)

```text
config     goal    full    beam
d=2 b=4   0.7464  0.5100  0.8442     ← ID
d=3 b=4   0.4302  0.3100  0.5930     ← depth -31.6pp
d=4 b=4   0.1333  0.1100  0.2741     ← depth -61.3pp
d=2 b=6   0.9275  0.8400  0.9529     ← budget +18.1pp (탐색이 깊이를 대체)
d=4 b=6   0.5111  0.4000  0.6889     ← 예산 확대로 13.3 → 51.1
```

읽기: 현재 셀은 **깊이 외삽에서 붕괴**하고, **예산 외삽은 안정**하다. 예산을
늘리면 깊이 손실의 상당 부분이 회복된다(13.3 → 51.1). 따라서 구조 탐색의 표적은
"더 많은 탐색"이 아니라 **한 번의 점수 계산 안에서 합성 단계를 표현하는 능력**이다.

## 3. 탐색 공간 (연역에서 유도한 셀 후보)

| 셀 | 연역적 근거 | 깊이 외삽 예상 | 구현 비용 |
|---|---|---|---|
| `setx` (기준) | 후보 집합을 독립 토큰으로 | 낮음 | 완료 |
| `hyper` | 원자를 노드, 규칙을 하이퍼엣지로 두고 body→head 메시지 전달 = closure 1스텝 | 높음 | 중 |
| `bilinear` | goal×rule을 술어·역할 임베딩의 쌍선형 형식으로 점수화 = unification 근사 | 중 | 낮음 |
| `recur` | 동일 step cell을 잔여 예산만큼 반복(가중치 공유) | 중~높음 | 중 |
| `obligation` | 잔여 목표 집합(의무)을 보조 표현으로 예측하고 그 감소량으로 점수화 | 높음 | 중 |
| `monotone` | 사실 추가에 단조인 점수(양수 가중·t-norm 집계) | 중 | 낮음 |

## 4. 탐색 프로토콜 (비용 2단)

1. **프록시 tier**: 1 시드 × 15 epoch, d=2/b=4 학습, ladder 5개 평가. 각 셀의
   `probe_score = mean_k (OOD_k − ID)` (깊이 두 칸 + 예산 두 칸). 표적 신호는
   `depth_gap`(ID − d4b4)과 `budget_gain`(d4b6 − d4b4).
2. **확인 tier**: 상위 2개 셀 × 5 시드 × 40 epoch, ladder 전체 + 2×2 데이터 조건
   재확인, paired world bootstrap.
3. **판정 규칙**: 셀이 `depth_gap`을 기준선 대비 사전 선언한 마진(10pp) 이상
   줄이고, ID 성능을 5pp 넘게 떨어뜨리지 않을 때 "구조 채택". 하나도 없으면
   null로 보고하고 셀 순위표를 남긴다(발견 절차는 0회 실행으로 끝나지 않는다).

## 5. 무엇을 "발견"으로 볼 것인가

- 단일 픽스처 성능 향상은 발견이 아니다. 채택 기준은 **구조 이동에서의 개선**이다.
- 셀 선택은 시드 3개 이상, 동일 파라미터·업데이트 예산, 동일 데이터 조건에서만
  비교한다. 파라미터 수가 다른 셀은 `params`를 함께 보고한다.
- 부정 결과도 표에 남긴다. 셀이 ID만 올리고 OOD를 못 올리면 "외삽 실패"로 기록한다.

## 6. 이미 확보한 것과 다음 작업

확보: 깊이·예산 knob, 깊이 독립 세계 스트림, 가중치 저장/로드(`--save-weights`,
`--load-weights`), ladder 러너(`run_probes.sh`), 기준선 표.

다음: `bilinear`, `recurrent`, `obligation`, `hyper` 셀을 순차 구현하고 프록시
tier를 돌린다. 0.0246에서 미구현으로 남긴 value target은 `obligation` 셀의 보조
목표로 흡수한다(잔여 목표 수 라벨은 이미 계산 가능).
