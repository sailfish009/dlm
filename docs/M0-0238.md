# M0 — DT-1 real-dimension, integer-Q16 inference parity

Worktree: `/research/dlm_v0.0238/experiments/dt_kernel_m0`

## Scope

M0 promotes the v0.0237 compact array-view kernels to the real DT-1 selector
dimensions and preserves the frozen v0.0218 selector semantics:

```text
D=32, F=64, MAXTOK=64
weight-tied block × 6 loops
196-bit image token + one token per valid rule
scalar per-rule head
kNN head prior
no positional encoding
bidirectional attention
```

M0 is inference parity only. It does not change the input to proof state (M1),
the objective to kernel utility (M2), or the selfssl seam (M3).

## Limits

- Inference parity, not training parity.
- Weight-tied 6-loop gradient flow is not checked.
- Rule bodies remain ≤64-bit masks; M1/M2 need indexed retrieval or `p-prove`.
- The tree still carries the v0.0237 runtime/VERSION; M0 is a worktree
  candidate, not a promoted release.
