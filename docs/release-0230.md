## What changed

- Added `experiments/web_synthetic_deductive_lab/`:
  - text-only web observations;
  - actual Maru parser for the web schema;
  - synthetic entities/chains generated from the extracted `isa/2` schema;
  - separate train/test synthetic facts and held-out entities;
  - transitivity learner `s-trans-synthesize`;
  - baseline/no-rule, learned-rule, negative and content-scramble gates.
- No Python is used in the lab.
