## 루프 셀: 상태 전이를 모델 내부로 (0.0269 구조 실험)

참조 transformer에도 없던 변경을 시도했습니다. 후보 순위 매기기(set transformer)는
그대로 두고, **증명 스텝 사이의 상태 전이를 모델 안으로** 넣었습니다.

### 설계

- 잠재 레지스터 z_t를 토큰 스택 맨 앞에 추가: `[z_t, state_t, candidates_t]`.
- 커밋된 행동 a_t 후 GRU-형 셀이 z를 갱신: `z_{t+1} = (1−u)⊙z_t + u⊙tanh(Wn[z_t; emb(a_t)])`,
  `u = sigmoid(Wu[z_t; emb(a_t)])`. 행동 임베딩은 후보 토큰과 같은 Wc를 공유.
- 학습은 **에피소드 BPTT**: teacher rollout(커널 검증済み)의 스텝들을 순서대로 forward,
  역순으로 backward하며 z를 통해 그래디언트가 스텝 간에 흐릅니다. 모든 arm이 같은
  에피소드 배치 프로토콜(8에피소드/업데이트, 23업데이트/epoch)을 씁니다 — 대조는 프로토콜 일치.
- 보조 목표(PREDW 0.5): **다음 상태의 최적 DP 값을 (z_t, emb(a_t))만으로 예측**하는
  월드모델 헤드. 커널이 타깃을 제공합니다.
- 통제: D_detach(전환 없는 정적 z0 토큰), D_shuf(셀에 회전된 행동 시퀀스 주입 —
  역사 내용 훼손, 학습량은 동일), D_rem(잔여예산 특징 슬롯 — 식별가능성 격차의
  비재귀적 해소), D_wide(블록 1개 추가 — 용량 대조), D_detachpred(정적 z0 + 예측 헤드).
- 추론에서도 z가 경로를 따라 진화합니다: greedy/beam/DFS 모두 노드별 z를 보유.
  계약(2규칙)은 규칙당 한 번씩 셀을 순차 적용합니다.

사전등록: 특징은 커널 closure에서 정확히 재계산되고(마르코프), 라벨은 정확한 DP 값입니다.
따라서 메모리리스 랭커가 정보적으로는 충분하며, 재귀는 최적화/근사 측면에서만
도움이 될 수 있습니다 — 정책 이득의 사전 기대치는 null이었습니다.

### 판정

1. **루프 셀(상태 전이의 내재화)은 정책 이득 null.** 사전등록대로입니다. 참 역사
   내용을 가진 셀이 훼손된 역사 제어보다 유의하게 낮습니다 — 잠재 상태의 내용이
   도움이 되기는커녕 약간 해롭습니다(노이즈 주입 regularization과 구별 불가).
2. **작은 양의 발견은 월드모델 보조 손실**(+2.3pp, 유의). 단 그 이득은 정적 z0에서도
   대부분 재현되고(+1.0pp), 동적 z 추가분은 ns — 메커니즘은 '전이 학습'이 아니라
   공유 임베딩을 형성하는 다중과제 regularization입니다.
3. 월드모델 헤드 자체는 학습됩니다(train MSE 14.28 → 0.43, 방향 게이트). 그러나
   val 타깃이 5.0에 집중(상수 기준선 MSE 0.36)이라 예측 정확도 자체에는 여지가
   없습니다 — val MSE 0.37 ≈ 기준선. 이 fixture에서 보조 목표의 가치는 표현 형성이지
   예측력이 아닙니다.
4. 잔여예산 특징(D_rem)도 null — 식별가능성 격차는 이 fixture에서 구속 조건이 아닙니다.
5. **예산-4의 남은 격차는 여전히 탐색 폭**입니다: branch 8 = 0.9254(천장의 98.8%,
   위 단순 루프)가 모든 모델-측면 변형(최고 0.9053)을 능가합니다. 모델 구조 축은
   이 fixture에서 소진됐다는 증거가 누적됐습니다 — 다음은 탐색 쪽(노드 효율,
   학습된 가지치기/순서)이거나 fixture 자체의 확장입니다.

### 엔지니어링 기록 (정직성 항목)

- 수동 역전파 BPTT: gradcheck가 에피소드 스칼라(학습 스칼라와 동일 함수)를 전
  파라미터(26,308개)에 대해 유한차분 검증, rel 2.6e-9. 셀 그래디언트 생생성
  (CELL-GRAD)을 별도 게이트 — 죽은 재귀가 0=0으로 통과하는 것을 차단.
- 개발 중 발견한 버그 2건: (a) param_count가 base+cell 개수를 세면서 flat 레이아웃의
  레지스터 간격(65 double)을 빼먹어 wv 전체와 Wv/bv 꼬리가 업데이트에서 제외됐습니다
  (예측 헤드 상수 고착으로 발견; gradcheck 범위도 같은 구멍을 가져 함께 수정).
  (b) 예측 헤드 tanh 포화 의심으로 Wv 초기화를 1/8로 줄였고, 실제 원인은 (a)였지만
  작은 초기화는 유지했습니다(선형 영역 시작, 포화 재발 방지).
- 에피소드 프로토콜은 A/B의 dfs를 약 5pp 낮춥니다(배치 구성 효과; D는 거의 불변).
  cross-version 비교는 프로토콜을 명시해야 합니다.
- Maru Q16 export는 LOOPCELL 빌드에서 명시적으로 거부됩니다(다중 스텝 z 체인의
  pst_infer 포팅은 후속 과제). Maru parity 게이트는 base 빌드에서 수행합니다.
- 순열 등변 게이트가 에피소드 수준으로 확장됐습니다(모든 스텝의 후보를 일관되게
