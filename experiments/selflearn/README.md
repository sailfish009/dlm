# experiments/selflearn — the model learns from its own source (v0.0057)

The most important purpose of model training is to **improve the model's
deduction** and, through recursive self-supervised learning, raise the DLM's own
ability toward the inductive ability of an LLM. So the subject of learning is
**the model's entire source** (`dlm/*.py`), and the improvement is measured on
facts the model never observed.

## What one run does

| stage | what happens | where |
|---|---|---|
| perceive | AST → generic facts (`defined`, `calls`, `private`, `documented`, `method`, `dunder`) and the intra-package call graph | `dlm.selflearn.perceive_facts` / `call_graph` |
| induce | search candidate 2-literal bodies; positives are multi-hop pairs generated by walking the model's own edges, negatives are sampled non-reachable pairs | `dlm.selflearn.induce_composition` |
| recurse | feed the induced law back through the kernel and reify each certified extension as the next relation (doubles reachable depth each round) | `dlm.selflearn.self_learn` |
| evaluate | recall of the ground-truth reachability (unobserved facts), vs. a one-composition control, plus a held-out edge split | `experiments/selflearn/run.py` |
| grow | recursively invent predicates so the hypothesis language keeps growing (a **definitional**, conservative extension) | `dlm.selflearn.grow_vocabulary` |

## Measured on the model itself (deterministic, offline)

```
graph      : 325 nodes, 500 edges
induction  : law=compose  tp=400 fp=0        (identity/reverse/swap all lose)
deduction  : one_shot recall=0.307  recursive recall=1.000  gain=+0.693
             round1 recall=0.474, round2=0.936, round3=1.000 (false=0)
held-out   : 100 edges held, 24 implied; one_shot=0.792 recursive=1.000
vocab      : features 355 -> 379, library=32, higher_order concepts=7
```

One composition recovers ~31% of the reachable pairs the model never observed;
**recursive self-supervision recovers 100% with zero false derivations.** This
is the measured improvement in deductive ability.

## The plateau this fixes

A v0.0056-style loop mined concepts over a **fixed** feature alphabet and
saturated (features stayed at 14; `concepts` stayed at 8). `grow_vocabulary`
reifies each round's certified concepts as new predicates and adds their
extension to the corpus, so the next round can quantify over them. The feature
alphabet grows every round (355 → 379 here) and later concepts are *higher-order*
(their bodies reference earlier invented predicates), so induction cannot
saturate on a finite vocabulary. This is reported **separately** because it is a
definitional extension: it names finer structure but adds no new entailment.

## Honest boundary

- The **law is induced** from examples (the search is scored on generated
  positives and sampled negatives); the *recursion mechanism* (inherit + compose)
  is the given self-supervision from v0.0055.
- The relational gain is exact and sound (kernel-decided, `false=0`). The
  vocabulary gain is descriptive, not additional entailment.
- The model's induction is restricted to a small, generic rule space over a given
  feature language. It recovers a transitivity law and grows a concept alphabet;
  it does **not** yet rival the open-ended induction of an LLM. That gap is the
  research target, not a claimed result.

## Run

> The single recursive-SSL entry point is `experiments/selfssl/selfssl.sh`; this
> bounded experiment remains as an internal validation module (no shell).

```bash
python3 experiments/selflearn/run.py
python3 experiments/selflearn/run.py --rounds 8 --max-body 2
```

Verdicts (`all_ok`): `law_induced_from_examples`, `induction_rejects_negatives`,
`induction_discriminates`, `recursion_beats_one_shot`, `recursive_reaches_closure`,
`no_false_derivations`, `held_out_recovery`, `vocabulary_grows`,
`higher_order_concepts`, `deterministic`.
