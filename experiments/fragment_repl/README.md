# fragment_repl — fragment decomposition and recombination (0.0158)

Run:

```bash
./scripts/experiment.sh
```

Five fragments are combined into four templates and four programs. The Maru REPL
curriculum selects two programs for four fixed tasks: `p-rec` is reused for three
task shapes and `p-comp` handles the composition shape.

This is a minimal structural assembly experiment, not a web extraction pipeline.
